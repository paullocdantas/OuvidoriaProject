# Sistema de Ouvidoria

Projeto desenvolvido para a disciplina de **Programar em Linguagem Estruturada**, do curso de Análise e Desenvolvimento de Sistemas (ADS).

## Sobre o projeto

O sistema foi desenvolvido em Python e utiliza o banco de dados MySQL para armazenar as manifestações cadastradas.

## Funcionalidades

- Cadastrar manifestações.
- Listar manifestações cadastradas.
- Pesquisar por tipo, nome ou protocolo.
- Remover manifestações.
- Gerar um protocolo para cada manifestação.

## Tecnologias utilizadas

- Python
- MySQL
- PyCharm
- Git e GitHub

## Como executar

Para executar o programa, é necessário ter o Python, o MySQL e a biblioteca `mysql-connector-python` instalados.

Também é preciso criar o banco de dados `ouvidoria`, configurar a conexão no arquivo `config_local.py` e executar o `main.py`.
